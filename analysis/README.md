# Analysis folder
- **scaraScript**: This folder is a Julia module that calculates the displacement of a beam given certain moment or load in the free end of a cantilever beam.
Assuming the first motor is totally rigid, the second arm is what gets the most
displacement of all of them.
So analyzing the loads vs displacement generated by the script we can determinate if the profile we're using could hold more than 30N that I assume it'll be more than enough for a small and slow Scara Robot.
> This approximation could be better if we use a FEM program to calculate the displacements. But that approach wont give us the same result as it isn't iterable enough to change the values faster without wasting too much resources.
